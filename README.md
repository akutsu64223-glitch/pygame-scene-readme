# 学習プロジェクト集 (pygame-scene-readme)

このリポジトリでは、以下の2つの独立したプロジェクトを管理しています。

- [シーン管理](./シーン管理) — Pygameによるゲームループとシーン管理のテンプレート
- [距離センサー](./距離センサー) — 距離センサー×音のリアルタイム変換プロジェクト

---

## シーン管理プロジェクト

**「Pygameを活用した、シーン管理機能付きの2Dアクションゲーム用テンプレートプログラム」**
* ゲーム開発の基本となる「ゲームループ（1秒間に60回の画面更新）」と「シーン管理（タイトル画面とゲーム画面の切り替え）」を実証するプログラムです。
* タイトル画面とゲーム画面を適切なキー入力で行き来しながら、画面上のプレイヤー（青い四角形）を自由に動かすことができます。

### 動作環境
* **言語/環境:** Python 3.10以上
* **必要なライブラリ:** pygame 2.0.0以上
* **対応OS:** Windows, macOS, Linux

### 始め方
```bash
pip install pygame
```

---

## 距離センサープロジェクト

**「Arduino Uno R4 WiFi + 超音波距離センサーで測った距離を、リアルタイムで音の高さに変換して鳴らすプログラム」**
* 距離が近いほど周波数が高く、遠いほど低くなる（指数マッピングを採用）
* Arduino側でセンサー値を計測してシリアル通信でPCに送信し、Python側で受け取って音を再生する構成

### 動作環境
* **言語/環境:** Python 3.10以上
* **必要なライブラリ:** pygame-ce, numpy, pyserial
* **ハードウェア:** Arduino Uno R4 WiFi, 超音波距離センサー(HC-SR04系)

### 始め方
```bash
pip install pygame-ce numpy pyserial
```

1. Arduinoスケッチをボードに書き込む(Trig=9番, Echo=10番ピン)
2. `python 距離センサー/sensor_to_sound.py COM3` を実行(COM3は環境に合わせて変更)
